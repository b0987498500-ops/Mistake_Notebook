## 📂 錯題本目錄結構與整理規則

錯題本檔案儲存於此目錄下，未來我們將依據學科或單元分類儲存。

- `README.md` (本檔案)：專案說明與版本資訊。
- `rules_log.md` (規則異動日誌)：記錄每一次我們約定好的錯題整理規則與異動時間。
- `math.md` (數學錯題本)：目前已建立的數學科錯題記錄。
- `chinese.md` (國文錯題本)：目前已建立的國文科錯題記錄。
- 其他科目（如自然、社會、英文）將在未來陸續建立對應的 Markdown 檔案（例如 `science.md` 等）。
